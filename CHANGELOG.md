# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-03-05
### Added
- Initial release of Burst Shot Cleaner.
- CustomTkinter GUI for scanning and cleaning burst shots.
- Detection logic based on timestamps (within 2 seconds) and naming patterns.
- Dry run mode for safe preview of cleaning operations.
- Progress bar and space saving summary.
- Automatic archive of cleaned images for safety.
